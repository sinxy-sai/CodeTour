# 哈希

核心思想：用值作为索引，快速记录或查询某个元素是否出现、出现次数、对应位置或对应状态。

为什么能快速查找：

- 数组可以 O(1) 访问，是因为数组是顺序存储，可以通过“数组起始地址 + 下标”直接找到元素。
- 哈希表也是借助数组实现快速访问，只是它先把 key 通过哈希函数转换成数组下标。
- 数组适合用连续整数下标访问；哈希表的优势是可以用字符串、大整数等更灵活的对象作为 key。
- 可以理解为：数组是“下标 -> 元素”，哈希表是“key -> 哈希函数 -> 下标 -> 元素”。

适用需求：

1. 判断是否出现过某个值。
   说明：需要快速回答“这个数/字符串之前见过吗”时，用哈希集合。

2. 统计每个值出现了多少次。
   说明：题目强调相同数字、相同字符串的出现次数，或不同位置也要分别计算时，用哈希表计数。

3. 快速寻找配对关系。
   说明：如果条件可以变形为“当前值需要另一个确定的值”，例如 A - B = C、两数之和等，可以用哈希表快速查找目标值。

4. 建立映射关系。
   说明：当需要把一个值对应到另一个信息，例如数字对应下标、字符串对应编号、状态对应答案时，用哈希表。

5. 去重。
   说明：只关心不同元素的种类，不关心顺序或重复次数时，用哈希集合。

常见工具：

- `set`：只记录元素是否存在。
- `dict`：记录元素和对应信息。
- `Counter`：专门统计元素出现次数。

语言对应：

- Python 中通常不会直接写“哈希表”这个名字，`dict`、`set`、`Counter` 背后用的都是哈希思想。
- C++ 中 `unordered_map`、`unordered_set` 是哈希表；`map`、`set` 通常是有序树结构，不是哈希表。

复杂度：

哈希表平均插入、查询、删除是 O(1)，整体通常可以把暴力枚举优化到 O(N) 或 O(N log N)。
